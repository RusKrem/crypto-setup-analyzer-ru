# Скриншоты GitHub-портфолио

В папке `docs/screenshots/` находятся шесть скриншотов реальной работающей версии Crypto Setup Analyzer RU 2.0:

1. `01-main-window.png` — главное окно визуального анализатора.
2. `02-rebound-scanner.png` — сканер отскоков альткоинов Binance Futures USDT-M.
3. `03-telegram-approach-message.png` — сообщение Telegram о приближении к уровню.
4. `04-telegram-confirmed-message.png` — сообщение Telegram о подтверждённой реакции.
5. `05-confirmed-reaction-card.png` — полная графическая карточка подтверждённой реакции.
6. `06-approach-card.png` — полная графическая карточка приближения к уровню.

Галерея уже подключена в `docs/index.html`. Перед публичной публикацией проверьте изображения на отсутствие токенов, приватных идентификаторов, личных данных и локальных путей. Скриншоты показывают интерфейс и реальные примеры данных на момент съёмки, но не являются торговыми рекомендациями.
