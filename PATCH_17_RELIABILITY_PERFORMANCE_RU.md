# PATCH 17: Дополнительная надёжность и производительность

## Что исправлено

- Исключение leveraged-токенов сканера теперь основано на точных суффиксах `UP`, `DOWN`, `BULL`, `BEAR`, а не на совпадении подстроки в любом месте тикера.
- Локальные события Observer получают стабильный SHA-256 ID из символа, типа события, направления, уровня и времени. Повторная запись одного события становится идемпотентной, разные временные события сохраняются отдельно.
- Поиск первого заполнения FVG переведён на segment tree: вместо полного прохода по будущим свечам для каждой зоны выполняется поиск первого пересечения по диапазонным минимумам/максимумам.
- Проверка инвалидирования Order Block использует заранее рассчитанные суффиксные экстремумы, без повторного сканирования хвоста DataFrame.
- `add_levels()` и `calculate_reference_levels()` используют общие критерии полноты UTC-окон; неполный предыдущий день больше не становится PDH/PDL в построчных колонках.
- Swing backtest отклоняет невалидный OHLC, повторяющиеся/неупорядоченные timestamps и некорректные параметры комиссии/проскальзывания.
- Telegram-карточки описывают наблюдаемое событие и не содержат рекомендаций о возможном входе.
- Рендерер карточек больше не меняет глобальный Matplotlib backend и сериализует операции построения через lock.
- В CI добавлена сборка Telegram Bridge через PyInstaller на Windows runner.
- `START.bat` прекращает запуск приложения, если не удалось создать venv или установить зависимости. Bridge build/rebuild BAT-файлы проверяют создание venv и не удаляют предыдущий EXE до начала успешной пересборки.
- Из Git удалён личный runtime log с локальным Windows-путём и сетевой диагностикой; локальные логи, lock-файл и рыночные CSV добавлены в ignore.

## Что остаётся ограничением

- Telegram Bot API не предоставляет idempotency key. Неоднозначные исходы отправки остаются в ручном карантине PATCH 14.
- Автоматическая сборка EXE в CI подтверждает сборку, но не заменяет проверку реальной доставки через VPN и пользовательскую конфигурацию Telegram.
- Расчёты и визуальные классификации не являются торговыми сигналами или гарантией результата.
