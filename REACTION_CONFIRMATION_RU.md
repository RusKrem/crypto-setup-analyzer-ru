# Подтверждение реакции и графические уведомления

## Два типа уведомлений

- `LEVEL_APPROACH`: предупреждение, когда цена находится в пределах 0,5% от ключевого уровня.
- `REACTION_CONFIRMED`: отдельная карточка после закрытия минутной свечи с выраженным отвержением.

## Начальные критерии отвержения

SHORT для уровней High (PDH, PWH, Today High): свеча касается/прокалывает уровень, закрывается ниже него, верхняя тень не менее 1,5 тела, закрытие в нижних 35% диапазона.

LONG для уровней Low (PDL, PWL, Today Low): свеча касается/прокалывает уровень, закрывается выше него, нижняя тень не менее 1,5 тела, закрытие в верхних 35% диапазона.

Проверяется только последняя полностью закрытая свеча 1m. Один сигнал подтверждения на уровень в рамках одного цикла приближения.

## Повторные предупреждения

После первого предупреждения повтор блокируется, пока цена не отойдёт дальше 0,7%. После такого выхода новое приближение до 0,5% может создать новое предупреждение.

## Telegram Bridge

Для отправки изображений Bridge использует Telegram `sendPhoto` с multipart upload. После распаковки новой версии необходимо пересобрать `TelegramBridge.exe` через `telegram_bridge/REBUILD_TELEGRAM_BRIDGE.bat` и добавить именно новый EXE в hide.me VPN routing. Не изменяйте токен и канал в `.env`; файл `.env` перенесите из предыдущей установки.

## Ограничения

Это экспериментальные фильтры, не торговая гарантия. Входы и ордера автоматически не открываются. Пороговые значения 1,5x / 35% являются начальными параметрами для последующего статистического тестирования.


## Графические уведомления Reversal Lab

- Карточки строятся по закрытым 1m OHLC-свечам Binance USDⓈ-M Futures (`fapi.binance.com`).
- В график попадают только реальные массивы kline; данные должны содержать минимум пять свечей, корректные OHLC и возрастающие open time.
- Для карточки подтверждения OHLC свечи отвержения сверяются с исходной свечой Binance по `candle_open_time`.
- Если реальные свечи недоступны или подтверждающая свеча не найдена в наборе, карточка не ставится в очередь. Текстовая подмена вместо графика запрещена.
- Оригинальная эмблема Reversal Lab хранится в `assets/reversal_lab_logo.png`; для вывода на тёмной карточке используется прозрачная версия `assets/reversal_lab_logo_transparent.png`.
- Telegram Bridge V51 не менялся: отправка изображения идёт через существующую очередь `telegram_queue` и метод Bot API `sendPhoto`.
