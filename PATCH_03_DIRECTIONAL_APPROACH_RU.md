# FIX 03 · Проверка стороны подхода к уровню

## Что исправлено

Сканер больше не создаёт предупреждение `LEVEL_APPROACH`, если цена уже находится по неправильную сторону уровня.

Правило для шести уровней:

- `PDL`, `PWL`, `Today Low` → `LONG`: цена должна быть выше уровня.
- `PDH`, `PWH`, `Today High` → `SHORT`: цена должна быть ниже уровня.

Проверка применяется в обоих местах формирования предупреждений:

1. `scan_symbol()` — резервная/прямая проверка цены.
2. `ReboundScanner._handle_price()` — основной WebSocket-поток и резервное обновление цен.

В событие приближения также добавлено поле `direction`, чтобы направление было явно передано дальше в уведомление и карточку.

Логика подтверждения реакции, порог 0,5%, ключи FIX 02 и гистерезис 0,7% не изменялись.

Неизвестные названия уровней не создают предупреждений, поскольку для них не определена сторона подхода.

## Установка

1. Полностью остановить основной сканер. Telegram Bridge можно не пересобирать: его код этим патчем не меняется.
2. Сделать резервную копию текущего `crypto_setup_analyzer/rebound_scanner.py`.
3. Распаковать архив поверх текущей папки проекта `Crypto_Setup_Analyzer_RU_v1_27`, сохраняя структуру каталогов.
4. Запустить основной сканер.
5. Для локальной проверки выполнить:

   `python -m unittest tests.test_rebound_scanner -v`

   Затем полный набор:

   `python -m unittest discover -v`

Патч не меняет Observer, его SQLite-базу, изображения, настройки, пороги или параметры стратегии.
