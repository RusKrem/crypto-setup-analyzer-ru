# PATCH 15: Единый источник Binance USDⓈ-M Futures

## Что исправлено

- Основной модуль рыночных данных ранее обращался к Binance Spot API, хотя README и карточки проекта заявляли USDⓈ-M Futures.
- REST endpoints свечей, списка контрактов и текущей цены переключены на `fapi.binance.com/fapi/v1`.
- В список инструментов основного графика попадают только активные USDT perpetual-контракты.
- UI теперь явно обозначает Binance USDⓈ-M Futures.
- Добавлены регрессионные тесты для URL endpoints, фильтрации perpetual-контрактов, текущей цены и последних свечей.
- Удалён сохранённый пример CSV, созданный старым Spot-источником, чтобы его нельзя было принять за фьючерсную историю. Локальная папка `data/` исключена из Git.

## Влияние

Основной график, историческая загрузка, realtime price и live candles теперь используют Futures. Отдельный сканер уже использовал USDⓈ-M Futures; его endpoint не менялся. Торговые условия и параметры сигналов не изменялись.

CSV, которые пользователь открывает вручную, остаются внешними данными: программа не может определить по OHLC-файлу, был ли он получен со Spot или Futures. Источник такого CSV следует проверять отдельно.

## Проверки

Добавлены тесты `tests/test_market_data_futures.py`. Результаты CI для последнего коммита указываются в GitHub Actions, а не фиксируются здесь заранее.
