# PATCH 16: UI, свечи и жизненный цикл окон

## Что исправлено

- Окно сканера повторно используется, если оно уже открыто; уничтоженное окно создаётся заново.
- Загрузка и анализ девяти таймфреймов для FVG перенесены в фоновый поток. Tk UI получает только готовый результат через `root.after`.
- События главного графика, реакции и order blocks рассчитываются по закрытым свечам. Формирующаяся свеча остаётся на графике и обновляется, но не создаёт преждевременные аналитические события.
- Проверки закрытой/формирующейся свечи и повторного использования окна добавлены в `tests/test_main_window.py`.

## Ограничения

- GUI acceptance test на реальной Windows-сессии требует запуска приложения с графическим рабочим столом.
- CSV-файл не содержит гарантированной информации об источнике и завершённости последней свечи. Для ручного CSV последняя строка считается доступной для анализа.
